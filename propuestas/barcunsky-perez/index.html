Tu sistema y tu dominio

La autogestión no se toca

La web es una portada aparte: no reemplaza ni modifica el portal de consorcios ni el sistema de alquileres que están armando. Solo los enlaza. Si mañana cambian de sistema, se cambia el link y listo.

Para la dirección de la web hay dos caminos:

Más simpleUn dominio propio: barcunskyperez.com.ar

Hoy aparece libre. Se registra a nombre de la firma y la web se aloja en una cuenta gratis a nombre de ustedes. Es más corto para decir y para poner en una tarjeta. El portal sigue en su dirección de siempre.

Si lo prefierenUsar admbarcunskyperez.com.ar

Ese dominio hoy lo maneja quien les da el sistema. Si quieren que la web quede ahí, lo coordino con ellos para que el portal siga andando igual. Como depende de ese proveedor, lo vemos antes de arrancar.

En los dos casos el precio es el mismo y los consorcistas siguen entrando como hoy.
