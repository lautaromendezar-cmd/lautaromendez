Auditoria SEO

Última actualización: 25 de octubre de 2026

Auditoria SEO es una herramienta interna de Lautaro Mendez para revisar el estado de los sitios web que hace y mantiene para sus clientes. No es un servicio abierto al público: la usa sólo él.

Qué datos de Google lee

Con el permiso de sólo lectura de Google Search Console (webmasters.readonly) lee, de las propiedades a las que la cuenta tiene acceso, las búsquedas, clics, impresiones y posiciones de cada sitio. No puede modificar nada en Search Console ni en ninguna otra cuenta de Google.

Para qué los usa

  • Detectar problemas en los sitios (páginas caídas, búsquedas que se pierden).
  • Armar recomendaciones e informes para el dueño de cada sitio.

Los datos no se venden, no se comparten con terceros y no se usan para publicidad ni para entrenar modelos de inteligencia artificial. El uso de la información recibida de las API de Google se ajusta a la Política de datos del usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Dónde se guardan

Los resultados de cada revisión se guardan en un almacenamiento privado en Vercel, al que sólo accede la herramienta. Las credenciales de acceso se guardan cifradas como variables de entorno y nunca se publican.

Cómo revocar el acceso

El acceso se quita en cualquier momento desde myaccount.google.com/permissions. Si querés que se borren los datos de tu sitio, escribime y los elimino.
